فونت‌ها: کاملاً بدون تغییر (Pofak + Liana + SHUTTLE-X + Typokar
         جاسازی‌شده داخل خود فایل HTML — هیچ فونتی عوض نشده)

───────────────────────────────────────────────────────────
روش ۱: نصب روی گوشی اندروید (پیشنهادی)
───────────────────────────────────────────────────────────

۱. کل محتویات این پوشه را روی یک هاست ساده آپلود کنید
   (مثلاً GitHub Pages، Netlify، یا هر هاست رایگان)
   یا روی کامپیوتر خود با یک سرور محلی اجرا کنید.

۲. آدرس را با مرورگر Chrome گوشی باز کنید.

۳. منوی سه نقطه Chrome → «Install app» یا «Add to Home screen»
   یا بنر «نصب برنامه» پایین صفحه را بزنید.

۴. آیکون اپ روی صفحه اصلی گوشی ظاهر می‌شود و مثل برنامه
   واقعی (بدون نوار آدرس مرورگر) باز می‌شود.

نکته: برای کار آفلاین، یک‌بار آنلاین باز کنید تا کش شود.
      بعد از آن بدون اینترنت هم کار می‌کند.

───────────────────────────────────────────────────────────
روش ۲: اجرای محلی روی کامپیوتر (برای تست)
───────────────────────────────────────────────────────────

اگر Node.js دارید:
  npx --yes http-server . -p 8080 -c-1

سپس در مرورگر بروید به:
  http://localhost:8080

───────────────────────────────────────────────────────────
روش ۳: باز کردن مستقیم فایل (محدود)
───────────────────────────────────────────────────────────

می‌توانید index.html را مستقیم با مرورگر باز کنید،
اما Service Worker و نصب PWA فقط روی http/https کار می‌کند
(نه روی file://).

───────────────────────────────────────────────────────────
فایل‌های موجود
───────────────────────────────────────────────────────────
index.html          → کل محتوا + فونت‌های جاسازی‌شده
manifest.webmanifest → اطلاعات نصب PWA
sw.js               → Service Worker برای حالت آفلاین
icons/              → آیکون‌های ۱۹۲ و ۵۱۲
